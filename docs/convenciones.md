## Nombres de ramas
feature/nombre-de-la-tarea     # Nueva funcionalidad
fix/nombre-del-bug             # Corrección de bug

Ejemplos:
feature/login-frontend
fix/error-registro-usuario

## Commits
Usar el ID de la tarea + descripción corta
Ejemplo: "formulario de registro con validaciones"

## Pull Requests
- Siempre hacia develop, nunca a main
- El título debe incluir el ID de la tarea
- Necesita al menos 1 aprobación antes de mergear
