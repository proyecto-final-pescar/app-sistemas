# My-Pet

Plataforma web para gestión de turnos veterinarios en Buenos Aires.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Base de datos: MongoDB Atlas
- Deploy: Vercel (frontend) + Render (backend)

## Equipo
Fundación Pescar Argentina 2026 — 10 integrantes
